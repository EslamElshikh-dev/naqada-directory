# دليل نقادة

دليل وموسوعة محلية عربية لمركز نقادة بمحافظة قنا. بُنيت الواجهة الحالية بـ Next.js 16 لتوفر صفحات مستقلة قابلة للفهرسة لكل نشاط وتصنيف وموضع، مع بحث عربي سريع وتجربة RTL متجاوبة.

## محتوى النسخة الحالية

- 244 صفحة نشاط وخدمة بحالة `ready` ودرجة توثيق `A`.
- 22 صفحة تصنيف متخصصة.
- أكثر من 80 صفحة موضع، تشمل 64 موضعًا في السجل الجغرافي الأساسي ونطاقات الأنشطة المسماة.
- 29 سجل عائلة أو فرع تاريخي مسموحًا بنشره.
- 10 شخصيات و12 معلمًا موثقًا.
- صفحات للطوارئ ومنهج البيانات، وملفات Sitemap وRobots وManifest تلقائية.

## التشغيل المحلي

```bash
npm install
npm run dev
```

الفحص قبل النشر:

```bash
npm run lint
npm test
npm run build
```

## النشر

المستودع مرتبط بمشروع Vercel، وأي تحديث معتمد على فرع `main` يبدأ نشرًا إنتاجيًا تلقائيًا.

## منهج البيانات

- لا تُعرض حالات `manual_review` أو `official_review` أو `research_only` أو درجة `C`.
- لا تُستنتج صلة نسب أو تبعية مكانية من تشابه الأسماء.
- بيانات الأنشطة دليل معلوماتي وليست اعتمادًا حكوميًا أو ضمانًا للخدمة.
- تُعرض درجات التوثيق والتنبيهات والمصادر العامة داخل السجلات التوثيقية.

التفاصيل التنفيذية موجودة في [PROJECT_NOTES.md](./PROJECT_NOTES.md).
