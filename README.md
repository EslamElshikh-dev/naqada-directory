# دليل نقادة

دليل محلي عربي لمركز نقادة يعرض الأنشطة والقرى والنجوع والعائلات والأعلام والمعالم من البيانات القابلة للنشر فقط.

## محتوى النسخة الحالية

- 244 سجل نشاط بحالة `ready`.
- 64 موضعًا منشورًا.
- 29 سجل عائلة أو فرع تاريخي مسموحًا بنشره.
- 10 شخصيات و12 معلمًا موثقًا.
- بحث عربي وفلاتر وصفحات مستقلة للقرى والعائلات والتراث ومنهج التوثيق.

## التشغيل المحلي

الموقع ثابت، وملفات النشر موجودة داخل مجلد `dist`.

```bash
npx serve dist
```

## النشر

المشروع مهيأ للنشر على Vercel من فرع `main`، ومجلد الإخراج هو `dist`.

## منهج البيانات

- لا تُعرض حالات `manual_review` أو `official_review` أو درجة `C`.
- لا تُستنتج صلة نسب من تشابه الأسماء.
- بيانات الأنشطة دليل معلوماتي وليست اعتمادًا حكوميًا أو ضمانًا للخدمة.

التفاصيل التنفيذية موجودة في [PROJECT_NOTES.md](./PROJECT_NOTES.md).
